
# 🍽️ Golden Plate Restaurant

Golden Plate is a modern and responsive restaurant website built with React, Tailwind CSS, and React Router. It features a clean design with a beautiful cream, gold, and brown color combination.

## 🌐 Pages

- **Home** – Hero section, popular dishes, why choose us, and special offers.
- **About** – Restaurant story, mission, vision, and values.
- **Services** – Restaurant services including dine-in, home delivery, takeaway, and catering.
- **Contact** – Contact information and a contact form.
- **404 Not Found** – Custom error page for invalid routes.

## ✨ Features

- Fully responsive design.
- Multi-page navigation using React Router.
- Reusable React components.
- Mobile-friendly navigation menu.
- Attractive restaurant hero section.
- Popular dishes section with food images and prices.
- Why Choose Us section.
- Special offer section.
- Contact form with basic frontend interaction.
- Custom 404 error page.
- Responsive footer.
- Modern UI with Tailwind CSS.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- Tailwind CSS
- React Router DOM
- React Icons
- Vite

## 🏠 Home Page Sections

The homepage contains four main sections:

1. **Hero Section** – Introduces the restaurant with attractive text and call-to-action buttons.
2. **Popular Dishes** – Displays popular food items with images, categories, and prices.
3. **Why Choose Us** – Highlights food quality, fresh ingredients, and customer service.
4. **Special Offer** – Encourages visitors to book a table.

## 🔗 Website Routes

| Page | Route |
|---|---|
| Home | `/` |
| About | `/about` |
| Services | `/services` |
| Contact | `/contact` |
| Not Found | `*` |

## 🎨 Design

- **Primary Background:** Cream (`#FFFCF5`)
- **Secondary Background:** Light Beige (`#F5EBDD`)
- **Primary Color:** Amber (`#B7791F`)
- **Footer Background:** Dark Brown (`#29231D`)
- **Text Color:** Stone

## 🖼️ Customization

You can customize the website by:

- Replacing placeholder food images with your own images.
- Updating restaurant information and contact details.
- Changing food names and prices.
- Updating social media links.
- Modifying colors and styles using Tailwind CSS.

## ⚠️ Important Notes

- The contact form currently provides frontend interaction only. It does not send messages to a backend or email service.
- Food prices, contact information, and images are sample content.
- Online ordering and payment functionality are not implemented.
